ScrollTrigger basics

Attach a scrollTrigger to a tween and it waits for a scroll position instead of playing immediately. The coloured lines on the right are markers: green = start, red = end. The animation happens when the element's line crosses the viewport's line.

Try this (edit main.js)

  1. Scroll slowly past each box, then scroll back up. Compare the four toggleActions.
  2. Change box 1's start to "top center" and watch the green markers move.
  3. Set once: true on box 4 — it animates the first time and then the trigger is removed.
