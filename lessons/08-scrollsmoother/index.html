ScrollSmoother

ScrollSmoother keeps the browser's native scroll but eases the content toward it, so it glides. It also gives you parallax for free with two HTML attributes — no JavaScript per element.

Try this

  1. In main.js, change smooth: 1.2 to 3, then to 0.3.
  2. In index.html, change the data-speed values. < 1 = slower than scroll, > 1 = faster.
  3. Try data-speed="auto" on an element inside a container with overflow: hidden (e.g. an image) — the classic image parallax.
