Pinning

pin: true freezes the trigger element in place from start to end, while the rest of the page keeps scrolling "behind" it. Combined with a scrubbed timeline you get the classic "the page stops and something happens" effect.

Try this (edit main.js)

  1. Change end: "+=2000" to "+=600". Same animation, much less scrolling.
  2. Set pin: false to see what the timeline looks like without pinning.
  3. Add snap: 1 / 3 to the scrollTrigger — it'll settle on the nearest step when you stop scrolling.
